# Spec: Fix UI Layout and Labels

## User Description
Fix UI layout, text wrapping, overlapping components, incorrect icons, remove extra parentheses like (sfdfs) or (0) from labels, and ensure correct sorting/filtering.

## Functional Requirements
- UI elements must not overlap.
- Labels must not contain extra parenthesized text like `(sfdfs)`, `(0)`.
- Correct icons must be used.
- Text must wrap correctly.
- Sorting/filtering functionality in channel/friend lists must be accurate.

## Success Criteria
- UI is clean, without overlapping.
- No extra parentheses in labels.
- Correct icons displayed.
- Sorting/filtering works as expected.
