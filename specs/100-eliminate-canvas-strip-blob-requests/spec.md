# Spec 100: Eliminate Canvas Strip Blob Request Flooding in Chrome DevTools Network Tab

## Problem Statement
When inspecting Chrome DevTools (F12 -> Network tab) in an active chat session with custom/preset wallpaper and translucent panels, users observe dozens of repeated requests:
- `blob:http://127.0.0.1:8085/<uuid>` (45+ requests, accumulating ~392 kB+ of memory/transfer)
- Preview shows `160 x 18` pixel cropped horizontal strips (`image/png`) of the background wallpaper.
- This creates the alarming appearance that the application is continually downloading unknown/unnecessary files ("toàn bị tải mấy cái gì không đâu à").

### Root Cause Analysis
1. In `app/web/adaptive_surface.js` (Spec 061 / Spec 073), `cropPanelStripBlobUrl` crops a 160x18 pixel canvas (`stripCanvas`) from `panelCanvas` and calls `stripCanvas.toBlob(blob => URL.createObjectURL(blob))` to set CSS custom properties `--chat-top-fade-strip` and `--chat-bot-fade-strip`.
2. Chromium's internal resource loader treats every `blob:` URL assigned to CSS `background-image: url("blob:...")` as an HTTP resource fetch and records each occurrence in the DevTools Network tab.
3. Whenever `syncChatEdgeFades` is invoked (via window resize, panel resizer drag, DOM mutations, chat selection, or the 800ms `ensureChatRo` interval), new `blob:` URLs are created. Even though previous blob URLs are revoked via `URL.revokeObjectURL`, the DevTools Network panel retains the historical network log entries, accumulating dozens of entries.
4. The chat header and composer already possess a modern, hardware-accelerated pure CSS gradient mask in `app/assets/main.css` (`mask-image: linear-gradient(...)` and `color-mix(...)`), rendering the canvas crop blob approach completely redundant and harmful to performance.

## Acceptance Criteria
- **AC1**: Zero `blob:` requests generated by canvas edge strips in Chrome DevTools Network tab.
- **AC2**: Completely remove `cropPanelStripBlobUrl`, `stripCanvas`, and related continuous blob allocations from `adaptive_surface.js`.
- **AC3**: Retain smooth, clean edge fading at the top (under `.chat-header`) and bottom (above `.composer`) via pure CSS gradient masking and color-mix.
- **AC4**: Zero visual or functional regression across wallpapers (image, sunset, ocean, bubbles, dark, light) and panel opacity settings.
- **AC5**: Automated Playwright E2E audit confirms clean Network tab without accumulating `blob:` requests.
